# 📽️ NaekWatch  

**NaekWatch** is a **streaming movie online with DUB** exclusively dedicated to **give a better experience of watching movie online**. This project showcases the **elegance, performance** of providing movie to All-ages service, while offering a seamless user experience.  

This project is part of an **end-of-course of Frontend final project Term 2**, designed to demonstrate skills in **web development and UI/UX design**.   

## Live Demo
Check out the live version of the project here: [NaekWatch Website](https://naek-watch.vercel.app/)


## 🛠️ Technologies Used  

- **React + Vite** – Utilized for component based architecture in order to mantaince and scalability for convient development.  
- **Tailwind** – Styling and creating a sleek, modern, and responsive design.  
- **JavaScript(ES6+)** – Adding interactivity for a dynamic user experience.  

## ✨ Features  

- **Elegant, UI/UX** with a **modern and responsive design**.  
- **Detail of movies display**, including with cast, director and writer.
- **Filtering movie** with many genere and country.  
- **Smooth animations and transitions** for a premium experience.  
- **Navigation bar and responsive layout** for optimal usability on all devices.    

## 🚀 Getting Started  
### 🔧 Installation  
1. **Clone the repository**  
   ```sh
   git clone https://github.com/developOnion/frontend-naek-watch.git
   cd frontend-naek-watch
   ```  

2. **Open `index.html` in a browser**
